    otel_nova_prom_exporter (opentelemetry_nova v0.4.0+build.34.ref93e5245)

    View Source

    Metric exporter that renders OpenTelemetry metrics in the Prometheus text format.

    Configure it as the exporter of an otel_metric_reader and serve the result with otel_nova_prom_server (or otel_nova_prom_handler on a listener of your own). Delta datapoints are accumulated into cumulative values, cumulative datapoints replace the stored value, so the output is correct for either reader temporality.

    Each metric keeps at most 2000 series. Datapoints for further attribute sets are added to one overflow series labelled otel_metric_overflow="true", so an unexpected source of label values cannot grow the table without bound. Label values that are not valid UTF-8 are rendered as _INVALID_UTF8.

    The table is written only by the process that called init/1, which is the metric reader.

    Implements the exporter API of both opentelemetry_experimental 0.6 (export/3, shutdown/1) and 0.5 (export/4, shutdown/1).
