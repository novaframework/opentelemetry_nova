    otel_nova_prom_server (opentelemetry_nova v0.4.0+build.34.ref93e5245)

    View Source

    HTTP listener serving otel_nova_prom_exporter output on /metrics.

    Start it from your supervision tree with child_spec/1 so the listener is stopped together with your application:

    init([]) ->
    Children = [otel_nova_prom_server:child_spec(#{port => 9464})],
    {ok, {#{strategy => one_for_one}, Children}}.

    The listener binds 127.0.0.1 and speaks HTTP/1.1 only, and /metrics has no authentication. Set ip (for example {0, 0, 0, 0}) to let a scraper on another host reach it, and restrict who can connect at the network level.
