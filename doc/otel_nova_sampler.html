    otel_nova_sampler (opentelemetry_nova v0.4.0+build.34.ref93e5245)

    View Source

    Sampler that drops server spans for excluded requests, such as health checks and Prometheus scrapes.

    Configure it with a list of "METHOD /path" binaries:

    {opentelemetry, [
    {sampler, {parent_based, #{root => {otel_nova_sampler, [~"GET /metrics", ~"GET /healthz"]}}}}
]}

    The decision is made when otel_nova_stream_h starts the server span, before Nova has routed the request, so the route template is not known yet. An entry is compared with the request method and the raw request path (the http.request.method and url.path attributes, without the query string), not with a route template: ~"GET /users/:id" does not match /users/42. An entry that equals the span name also matches, for server spans started elsewhere with a final name.

    Only server spans are dropped. Wrapped in parent_based, it decides for root spans only; a request with a sampled traceparent follows its parent.
