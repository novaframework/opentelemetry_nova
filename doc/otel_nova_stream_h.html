    Cowboy stream handler that creates the HTTP server span and records the HTTP server metrics.

    Cowboy runs stream handlers in the connection process, while Nova middleware, plugins and controllers run in a separate request process. The handler therefore never touches the connection process context. It stores the request context in the Req under otel_nova_ctx, and otel_nova_plugin attaches it in the request process, so spans created there are children of the server span.

    Instrumentation failures are logged without request data and never crash the stream, and the server span is started even when building its attributes fails.

    Options, read from the opentelemetry_nova application environment:

    • trust_forwarded_for (default false): take client.address from the first X-Forwarded-For entry or the Forwarded header when it is a valid IP address. Otherwise it is the peer address.
    • metric_server_hosts (default unset): a list of hosts recorded as the server.address metric attribute, together with the listener port as server.port. Other hosts are recorded as _OTHER. When unset, neither attribute is recorded on metrics.
    • trust_incoming_context (default true): continue the trace context and baggage the client sends. When false the server span starts a new trace and links to the remote parent.

    The method is normalised to one of the nine standard methods or _OTHER, on both spans and metrics. Spans keep the sent value as http.request.method_original when it differs.
